# Galaxea R1

![R1_title](assets/R1_title.png)



## 精确度 & 灵活性

Galaxea R1 是一款全尺寸仿人型机器人，具备下触地面、上达2米的操作范围以及至少70厘米的单臂操作半径。全身共有24自由度，确保其在各种操作环境中展现出卓越的机动性与适应性。
