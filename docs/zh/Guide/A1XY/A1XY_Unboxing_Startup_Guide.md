## 2. 安装本体

- 请选择合适的安装平台，确保平台平整、稳固，能够承受机械臂在运行过程中的最大负载。
- 请清洁安装平台表面，去除杂物、灰尘等可能影响安装稳定性的物质，保证安装底座板与平台之间的紧密贴合。

按照以下步骤安装固定机械臂：

1. 将G夹转接板放置在选定的安装平台或桌面上，确保其位置合适，便于后续的固定操作。
2. 使用G夹固定好转接板。
3. 将机械臂小心地放置在转接板中央，确保机械臂底座四周的孔位与G夹转接板的孔位准确对接，使用M6螺丝固定机械臂。

## 3. 连接线束

![A1XY_connection_cn](./assets/A1XY_connection_cn.png)

1. 连接USB-CAN线至上位机和CAN盒。
2. 连接线束包中的CAN线两端至机械臂底座的CAN线接口和CAN盒的CAN1接口，并将CAN盒的电阻开关R1、R2均拨至顶部。
3. 连接开关电路的两端至机械臂底座的供电口和电源适配器。
4. 将电源适配器接入电源中。

连接成功后，即可开机启动机械臂，并开始启动控制。

## 4. 启动前准备

### 4.1 下载SDK包

- 百度云：
- Google Drive：

当前为A1XY机械臂的首发软件版本。后续的版本更新您可以在A1XY软件版本更新日志中查看，获取最新的SDK包及更新信息。

### 4.2 安装SDK

执行以下命令检查通信连接状态。

```Bash
ifconfig can0
```

执行以下命令安装SDK：

```Bash
tar -xf ${your_download_path}/R1_LITE_SDK.tar.gz -C ~/
chmod +x install.sh
cd ~/
./install.sh
```

- SDK文件仅支持X86架构。
- 安装脚本将创建`{$home}/work/galaxea`文件夹。

## 5. 启动CAN驱动程序

在控制A1XY的整个过程中，您需要打开多个终端。我们建议您使用TMUX。常用指令如下：

- 创建新终端：按`Ctrl + B`然后按`C`。
- 切换终端：按`Ctrl + B`然后按数字，数字表示终端窗口的序号。

现在，您可以按照以下步骤启动CAN驱动程序。

1. 启动TMUX。

    ```Bash
    tmux
    ```

2. 启动FDCAN通信。

    ```Bash
    ./can.bash    
    ```

3. 启动roscore。

    ```Bash
    roscore    
    ```

4. 按`Ctrl + B`然后按`C`创建新终端。然后启动HDAS。

    ```Bash
    source ~/work/ci_pipeline/workspace/body/install/setup.bash
    roslaunch HDAS hdas.launch
    ```

## 6. 启动控制

1. 设置 SocketCAN 接口和 can0。

    ```Bash
    sudo ip link set dev can0 type can bitrate 1000000 dbitrate 5000000 fd on
    sudo ip link set up can0
    ```

2. 运行以下命令以转储 CAN 总线消息。

    ```Bash
    candump can0
    ```
    ![img]()

3. 按`Ctrl + B`然后按`C`创建新终端。运行以下命令以启用硬件接口和ROS接口。

    ```Bash
    source ~/work/galaxea/install/setup.bash
    roslaunch HDAS hdas.launch
    roslaunch mobiman a1_x_jointTrackerdemo.launch （a1_x）
    roslaunch mobiman a1_y_jointTrackerdemo.launch （a1_y）
    ```
