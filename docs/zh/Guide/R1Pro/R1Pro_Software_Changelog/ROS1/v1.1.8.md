# Galaxea R1 Pro 软件版本 - V1.1.8 - 更新日志

## 更新说明

**产品名称：** Galaxea R1 Pro

**软件版本号：** V1.1.8

**Ubuntu 系统：** 20.04 LTS

**ROS版本：** ROS 1 Noetic

**发布日期：** 2025.5.7

**更新项：**

1. **驱动内容更新项：**

      a）修复VR遥操作时双臂和夹爪不可动问题。

3. **导航功能更新项：**

      a）优化速度滤波器，防止速度突变； 
      
      b）修复失败反馈状态问题。

## 更新教程
### 下载更新包

`atc_standard-V1.1.8.tar.gz`

- 百度云：[R1 Pro SDK V1.1.8](https://pan.baidu.com/s/19zWgeqxha40Mmu7sGznIYQ?pwd=v118)
- Google Drive：[R1 Pro SDK V1.1.8](https://drive.google.com/drive/folders/1yeBBmdN1uhNZn7att6LNYVOrpNBLwz5y?usp=sharing)

### 解压更新包

```Bash
tar -xf ${your_download_path}/atc_standard-V1.1.8.tar.gz -C ~/
```
