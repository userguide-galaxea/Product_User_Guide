# Galaxea R1 Pro软件版本 - V2.0.1 - 更新日志

## 更新说明

**产品名称：**Galaxea R1 Pro

**软件版本号：**V2.0.1

**Ubuntu 系统：** 22.04 LTS

**ROS版本：** ROS 2 Humble

**发布日期：**2025.4.23

**更新项：**

本次迁移仅包含R1 Pro的本体（即R1ProBody）相关的模块，支持功能与R1 Pro ROS 1 Noetic SDK V1.1.7一致。

1. 软件系统更新项：

    a）更新操作环境为Ubuntu 22.04 LTS。  

    b）更新机器人操作系统为ROS 2 Humble。
    
2. 运控内容更新项：

    a）新增R1 Pro VR遥操作功能。

3. 驱动内容更新项：

    a）优化控制器固件。

## 更新说明

1. 在升级过程中，请不要中止系统运行，也不要进行任何控制操作，否则可能导致升级失败，影响系统正常使用。

## 更新教程
### 下载更新包

`atc_standard-V2.0.1.tar.gz`

- 百度云：[R1 Pro SDK V2.0.1](https://pan.baidu.com/s/1jtx2__dnKTorvPYbJ6TRNg?pwd=v201)
- Google Drive：[R1 Pro SDK V2.0.1](https://drive.google.com/drive/folders/1ogSQ39SNX0DFtiUSNoHRA-zVV2GRCC8z?usp=sharing)

### 解压更新包

```Bash
tar -xf ${your_download_path}/atc_standard-V2.0.1.tar.gz -C ~/
cd ~/
find ./install -name "*.sh" -exec sudo chmod +x {} \;
```

### 启动CAN通信

```Bash
# 终端1
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000 dbitrate 5000000 fd on       
sudo ip link set can0 up
```

### 更新嵌入式固件

```Bash
# 终端2
cd ~/ && source install/setup.bash
cd ~/install/Embedded_Software_Firmware/share/tools/R1PRO
sudo chmod +x r1pro_embedded_firmware_upgrade.sh
./r1pro_embedded_firmware_upgrade.sh ../../firmware/R1PRO/V2_0_1
```

等待几秒后，出现“GET OTA finished!！”即表示更新成功。
![sdk_ros2_xcu_cn](../assets/sdk_ros2_xcu_cn.png)

<span style="color:red;">**注意：更新完毕后，请关闭机器人电源并重新上电。**</span>

### 运行模块

```Bash
cd install/startup_config/share/startup_config/script/
# R1PRO BODY：
./robot_startup.sh boot ../session.d/ATCStandard/R1PROBody.d/
# R1PRO VRTELEOP：
./robot_startup.sh boot ../session.d/ATCStandard/R1PROVRTeleop.d/
```
