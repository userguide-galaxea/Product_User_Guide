# Galaxea R1软件版本 - V1.1.0 - 更新日志

## 更新说明

**产品名称：**Galaxea R1

**软件版本号：**V1.1.0

**发布日期：**2025.2.21

**更新项：**

1. **智能产品上线——自主导航系统：**<br>
   a) **<u>定位模块</u>**：通过激光雷达等传感器数据对机器人当前位姿进行估计和更新。该模块包括全局定位功能和里程计功能，能够结合多种传感器数据实现高精度的定位。<br>
   b) **<u>路径规划模块</u>**：用于生成最优路径并指导机器人完成导航任务。该模块包括全局路径搜索和局部路径规划功能。全局路径搜索根据机器人当前位姿和目标位姿，确定机器人的全局导航路径；局部路径规划则在全局路径的基础上，结合障碍物信息，进一步生成安全可行的局部路径。<br>
   **<span style="color:blue;">自主导航系统为付费启用功能，目前处于测试阶段，如需深入了解及购买试用，请联系product@galaxea.ai或致电4008780980。</span>**

2. **遥操作产品上线：**<br>
   a) **<u>R1 Teleop 同构遥操作</u>**：相关产品使用说明与SDK已发布上线，点击[此处](../R1_Teleop_Usage_Tutorial.md)查看；<br> 
   b) **<u>R1 VR Teleop 遥操作</u>**：相关产品使用说明与SDK已发布上线，点击[此处](../R1_VR_Teleop_Usage_Tutorial.md)查看。

3. **运控内容更新项：**<br>
   a) **<u>新增关节控制器参数配置</u>**：允许外部用户直接读取并调整关节控制器的 kp（位置增益比例）和 kd（速度增益比例）参数。目录位置`SDK/install/share/mobiman/config/joint_controller_kp_kd.toml`（参数列表中的Index对应相应电机的ID）。

4. **驱动内容更新项：**<br>
   a) **<u>新增双臂控制模式切换功能</u>**：支持伺服模式和力位混合模式切换功能，用户可以根据实际需求灵活切换。



## 更新说明

1. 升级脚本会默认删除**<span style="color:orange;">/home/nvidia/work/ci_pipeline</span>**下的所有文件，请您务必在升级前确认该文件夹内的文件已做好备份工作，以免造成数据丢失。
2. 在进行OTA升级前，请先将机器人R1安装完整（包括双臂），以免出现更新失败。
3. 在升级过程中，请不要中止系统运行，也不要进行任何控制操作，否则可能导致升级失败，影响系统正常使用。
4. 升级完成后，请关闭 R1 电源，并重新进行上电操作，以确保系统更新完全生效。

**请严格按照以下教程完成本次系统更新，如遇问题，请及时联系我们至 [support@galaxea.ai](mailto:support@galaxea.ai)获得技术支持!**

### 解压更新包

```Bash
tar -xf ${your_download_path}/Software_V1.1.0_Release.tar.gz -C ~/
chmod +x ~/ota.sh
cd ~
./ota.sh
```

### 更新嵌入式固件

```Bash
cd ~/work/galaxea/install/share/Embedded_Software_Firmware/tools/R1
source ~/work/galaxea/install/setup.bash
bash r1_embedded_firmware_upgrade.sh ../../R1/V1_1_0
```
