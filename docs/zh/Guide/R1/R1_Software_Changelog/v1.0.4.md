# Galaxea R1软件版本 - V1.0.4 - 更新日志

## 更新说明

**产品名称：**Galaxea R1

**软件版本号：**V1.0.4

**发布日期：**2025.1.16

**更新项：**

1. **导航智能产品上线：**
   a) 新增定位模块，涵盖全局定位功能和里程计功能；
   b) 新增规划模块，涵盖全局路径搜索和局部路径规划功能。
   **<span style="color:blue;">如有购买需求，请致电400 780 980或邮件至 [info@galaxea.ai](mailto:info@galaxea.ai)。</span>**

2. **运控内容更新项：**
   a) 修复chassis control 的低速跟随问题;
   b) 新增高跟随模式的关节控制命令；
   c) 新增躯干控线速度控制，该命令不能与Joint Tracker同时启动;
   d) 新增禁用躯干控制功能，用于特定测试。

3. **HDAS内容更新项：**
   a) 新增R1 Pro协议解析：roslaunch HDAS r1pro.launch，支持A2机械臂搭载灵巧手/夹爪接口；
   b) HDAS修复CAN无消息情况下CPU占用100%问题。

4. **xCU嵌入式内容更新项：**
   a) 新增CCU调低风扇速度功能；
   b) 新增底盘VCU Errorcode上报。


## 更新说明

1. 升级脚本会默认删除**<span style="color:orange;">/home/nvidia/work/ci_pipeline</span>**下的所有文件，请您务必在升级前确认该文件夹内的文件已做好备份工作，以免造成数据丢失。
2. 在升级过程中，请不要中止系统运行，也不要进行任何控制操作，否则可能导致升级失败，影响系统正常使用。
3. 升级完成后，请关闭 R1 电源，并重新进行上电操作，以确保系统更新完全生效。

**请严格按照以下教程完成本次系统更新，如遇问题，请及时联系我们至 [info@galaxea.ai](mailto:info@galaxea.ai)获得技术支持!**



## 更新教程

### 下载更新包

“Software_V1.0.4_Release.tar.gz”

- 百度云：https://pan.baidu.com/s/1BVzYb3EWsbrJ9ANOo_psNQ?pwd=V104
- Google Drive：https://drive.google.com/drive/folders/1BRQXwE6emFTTZhMeqXbdcG1J3bjrawR0?usp=drive_link

### 解压更新包

```Bash
tar -xf ${your_download_path}/Software_V1.0.4_Release.tar.gz -C ~/
chmod +x ~/ota.sh
cd ~
./ota.sh
```

### 更新XCU

```Bash
cd ~/work/galaxea/install/share/Embedded_Software_Firmware/tools/R1
source ~/work/galaxea/install/setup.bash
bash r1_embedded_firmware_upgrade.sh ../../firmware/R1/V1_0_4
```

![R1_update_XCU](assets/R1_update_XCU.png)

**<span style="color:red;">注意：更新完毕后，请关闭R1电源并重新上电</span>**

### 运行模块

```Bash
sudo apt-get install tmux tmuxp
cd ~/work/galaxea/install/share/startup_config/script
./ota_script.sh boot
```
