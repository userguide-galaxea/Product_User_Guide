# Galaxea R1软件版本 - V1.1.8 - 更新日志

## 更新说明

**产品名称：** Galaxea R1

**软件版本号：** V1.1.8

**Ubuntu 系统：** 20.04 LTS

**ROS版本：** ROS 1 Noetic

**发布日期：** 2025.5.7

**更新项：**

1. **运控内容更新项：**

      a）新增躯干关节控制`r1_jointTracker`的`disable_torso`禁用躯干功能，实现躯干速度控制时，躯干关节控制不会抢占控制topic，避免控制冲突。

2. **驱动内容更新项：**

      a）修复VR遥操作时双臂和夹爪不可动问题。

3. **导航功能更新项：**

      a）优化速度滤波器，防止速度突变； 
      
      b）修复失败反馈状态问题。

## 更新教程
### 下载更新包

`atc_standard-V1.1.8.tar.gz`

- 百度云：[R1 SDK V1.1.8](https://pan.baidu.com/s/1EHfcALZ6R9EbReqIi1MG_g?pwd=v118)
- Google Drive：[R1 SDK V1.1.8](https://drive.google.com/drive/folders/1_ivv2CuCIm4rgv6bJvz62NO9ZtNpHQEr?usp=sharing)

### 解压更新包

```Bash
tar -xf ${your_download_path}/atc_standard-V1.1.8.tar.gz -C ~/
```

### 更新驱动软件版本

```Bash
cd {your_download_path}/install/share/Embedded_Software_Firmware/tools/{your_product_name}
bash {your_product_name}_embedded_firmware_upgrade.sh ../../{your_product_name}/V1_1_8
```

### 运行模块

```Bash
cd {your_download_path}/install/share/startup_config/script

# R1 BODY：
./robot_startup.sh boot ../session.d/ATCStandard/R1Body.d/

# R1 VR TELEOP：
./robot_startup.sh boot ../session.d/ATCStandard/R1VRTeleop.d/
```
