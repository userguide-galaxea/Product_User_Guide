# Galaxea R1软件版本 - V1.1.4 - 更新日志

## 更新说明

**产品名称：** Galaxea R1/R1 Pro/R1 Lite

**软件版本号：** V1.1.4

**Ubuntu 系统：** 20.04 LTS

**ROS版本：** ROS 1 Noetic

**发布日期：** 2025.4.2

**更新项：**

1. **遥操作产品上线：**

      a）R1 Pro VR Teleop 遥操作：相关产品使用说明与SDK已发布上线，点击[此处](../../../R1Pro/R1Pro_VR_Teleop_Usage_Tutorial.md)查看。

      <span style="color:blue;">**自主导航系统为付费启用功能，如需深入了解及购买试用，请联系product@galaxea.ai或致电4008780980。**</span>

2. **运控内容更新项：**

      a）新增R1 Pro的VR Teleop遥操作功能；

      b）增加夹爪功能；

      c）提升躯干控制速度，并优化奇异点电锯速度过高的问题；

      d）更新导航模块的速度控制更新为`TwistStamped`；

      e）优化R1 Lite 的躯干关节控制。


3. **驱动内容更新项：**

      a）增加R1 Pro整机OTA功能；

      b）增加R1 Lite的OTA功能。



## 更新说明

1. 升级脚本会默认删除**<span style="color:orange;">/home/nvidia/work/ci_pipeline</span>**下的所有文件，请您务必在升级前确认该文件夹内的文件已做好备份工作，以免造成数据丢失。
2. 在进行OTA升级前，请先将机器人安装完整（包括双臂），以免出现更新失败。
3. 在升级过程中，请不要中止系统运行，也不要进行任何控制操作，否则可能导致升级失败，影响系统正常使用。
4. 升级完成后，请关闭机器人电源，并重新进行上电操作，以确保系统更新完全生效。

<span style="color:red;">**请严格按照以下教程完成本次系统更新，如遇问题，请及时联系我们至 [support@galaxea.ai](mailto:support@galaxea.ai)获得技术支持!**</span>



## 更新教程
### 下载更新包

`Software_V1.1.4_Release.tar.gz`

- 百度云：[R1 SDK V1.1.4](https://pan.baidu.com/s/1PEh_CVav9FPtJwCF90xl4Q?pwd=V114)
- Google Drive：[R1 SDK V1.1.4](https://drive.google.com/file/d/184gggQWirduP9MjvXuof-vdtJyB3j8Ks/view?usp=sharing)

### 解压更新包

```Bash
tar -xf ${your_download_path}/Software_V1.1.4_Release.tar.gz -C ~/
chmod +x ~/ota.sh
cd ~
./ota.sh
```
