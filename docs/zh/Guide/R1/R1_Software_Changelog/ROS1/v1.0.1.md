# Galaxea R1软件版本 - V1.0.1 - 更新日志

## 更新说明

**产品名称：**Galaxea R1

**软件版本号：**V1.0.1

**Ubuntu 系统：** 20.04 LTS

**ROS版本：** ROS 1 Noetic

**发布日期：**2024.12.11

**更新项：**

1. 修复check_node检查中的漏洞;
2. 更新URDF V_2_1_0，其坐标系对齐Mobiman；
3. 更新XCU，提升TCU和CCU IMU分辨率有效位至0.000x级别；
4. 优化Livox_ros_driver中的lidar数据格式。


## 更新说明

1. 升级脚本会默认删除**<span style="color:orange;">/home/nvidia/work/ci_pipeline</span>**下的所有文件，请您务必在升级前确认该文件夹内的文件已做好备份工作，以免造成数据丢失。
2. 在进行OTA升级前，请先将机器人R1安装完整（包括双臂），以免出现更新失败。
3. 在升级过程中，请不要中止系统运行，也不要进行任何控制操作，否则可能导致升级失败，影响系统正常使用。
4. 升级完成后，请关闭 R1 电源，并重新进行上电操作，以确保系统更新完全生效。

**请严格按照以下教程完成本次系统更新，如遇问题，请及时联系我们至 [support@galaxea.ai](mailto:support@galaxea.ai)获得技术支持!**



## 更新教程

### 下载更新包

`Software_V1.0.1_Release.tar.gz`

- 百度云：[R1 SDK V1.0.1](https://pan.baidu.com/s/180CLkkcj3tpgCgmfvACDqA?pwd=V101)
- Google Drive：[R1 SDK V1.0.1](https://drive.google.com/drive/folders/17zY5MTDQP9oIlaFrrykmaYQ1YBggDJCh?usp=sharing)

### 解压更新包

```Bash
tar -xf ${your_download_path}/Software_V1.1.0_Release.tar.gz -C ~/
chmod +x ~/ota.sh
cd ~
./ota.sh
```

### 更新嵌入式固件

```Bash
cd ~/work/galaxea/install/share/Embedded_Software_Firmware/tools/R1
source ~/work/galaxea/install/setup.bash
bash r1_embedded_firmware_upgrade.sh ../../firmware/R1/V1_0_0
```

![R1_update_XCU](assets/R1_update_XCU.png)

**<span style="color:red;">注意：更新完毕后，请关闭R1电源并重新上电</span>**

### 运行模块

```Bash
cd ~/work/galaxea/install/share/startup_config/script/
./ota_script.sh boot
```
