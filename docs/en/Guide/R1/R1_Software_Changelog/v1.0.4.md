# Galaxea R1 Software Version_V1.0.4_Changelog

## Release Notes

**Product Name:** Galaxea R1

**Software Version:** SDK V1.0.4

**Release Date:** January 16, 2025 (GMT +8)

**Update Content:**

1. **Navigation Smart Product Launch:**
   a) Introduced Localization Module: Includes global localization and odometry capabilities.
   b) Introduced Planning Module: Includes global path search and local path planning capabilities.
   **<span style="color:blue;">For purchase inquiries, please call 4008 780 980 or email to [info@galaxea.ai](mailto:info@galaxea.ai).</span>**

2. **Motion Control Update Items:**
   a) Resolved the low-speed following issue in chassis control.
   b) Introduced joint control commands for high-follow mode.
   c) Introduced torso linear velocity control. (Note: This command cannot run simultaneously with the Joint Tracker.)
   d) Introduced functionality to disable torso control for specific tests.

3. **HDAS Update Items:**
   a) Introduced R1 Pro protocol parsing: roslaunch HDAS r1pro.launch，supporting A2 robot arm equipped with a dexterous hand or gripper interface.
   b) Fixed the issue in HDAS where CPU utilization reached 100% when no CAN messages were received.

4. **xCU Embedded Update Items:**
   a) Introduced functionality of CCU fan speed to a lower level.
   b) Introduced chassis VCU Errorcode reporting.



## Update Instruction

1. The upgrade script will automatically delete all files in **<span style="color:orange;">/home/nvidia/work/ci_pipeline</span>**. Please ensure that all files in this directory are backed up before upgrading to avoid data loss.
2. During the upgrade process, do not interrupt the system operation or perform any control actions, as this may cause the upgrade to fail and affect normal system operation.
3. After the upgrade is complete, power off the R1 system and then power it back on to ensure the update is fully applied.

**Please follow the tutorial below to complete this system update. If you encounter any issues, feel free to contact us at
<span style="color:blue;">[info@galaxea.ai](mailto:info@galaxea.ai)</span> for technical support!**




## Update Tutorial

### Download the Update Package

“Software_V1.0.4_Release.tar.gz”

- Baidu Cloud：https://pan.baidu.com/s/1BVzYb3EWsbrJ9ANOo_psNQ?pwd=V104
- Google Drive：https://drive.google.com/drive/folders/1BRQXwE6emFTTZhMeqXbdcG1J3bjrawR0?usp=drive_link

### Extract the Package

```Bash
tar -xf ${your_download_path}/Software_V1.0.4_Release.tar.gz -C ~/
chmod +x ~/ota.sh
cd ~
./ota.sh
```

### Update XCU

```Bash
cd ~/work/galaxea/install/share/Embedded_Software_Firmware/tools/R1
source ~/work/galaxea/install/setup.bash
bash r1_embedded_firmware_upgrade.sh ../../firmware/R1/V1_0_4
```

![R1_update_XCU](assets/R1_update_XCU.png)

**<span style="color:red;">Note: After completing the update, power off the R1 and then power it back on.</span>**

### Execute the Module

```Bash
sudo apt-get install tmux tmuxp
cd ~/work/galaxea/install/share/startup_config/script
./ota_script.sh boot
```
