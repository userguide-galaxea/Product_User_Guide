# Galaxea R1 Software Version_V1.0.4_Changelog

## Release Notes

**Product Name:** Galaxea R1/R1 Pro

**Software Version:** V1.0.4

**Release Date:** January 17, 2025 (GMT +8)

**Update Content:**

1. **Navigation Smart Product Launch:**<br>
   a) **Localization Module** introduced, including global localization and odometry capabilities. <br>
   b) **Planning Module** introduced, including global path search and local path planning capabilities.<br>
   **<span style="color:blue;">For any inquiry, please email to [info@galaxea.ai](mailto:info@galaxea.ai) or call 4008-780-980.</span>**

2. **Motion Control Update Items:**<br>
   a) Solve the low-speed following issue in Chassis Control.<br>
   b) Introduce **dynamic-following mode** for Arm Control in terms of joint-level control.<br>
   c) Introduce **Torso linear velocity control**: This command cannot run simultaneously with the Joint Tracker.<br>
   d) Introduce functionality to disable Torso Control for specific tests.

3. **Driver (HDAS) Update Items:**<br>
   a) **R1 Pro protocol** parsing introduced: `roslaunch HDAS r1pro.launch`, supporting **A2 robot arm** equipped with a **dexterous hand** / gripper interface.<br>
   b) Fix the issue in HDAS where CPU utilization reached 100% when no CAN messages were received.<br>

4. **Embedded Firmware (xCU) Update Items:**<br>
   a) Introduce the functionality of fan speed control of CCU(Central Control Unit).<br>
   b) Introduce **chassis control errorcode reporting** of VCU(Vehicle Control Unit).



## Update Instruction

1. **<span style="color:red;">CAUTION:</span>** The upgrade script will automatically delete all files in **`/home/nvidia/work/ci_pipeline`**. Please ensure that all files in this directory are backed up before upgrading to avoid data loss.
2. During the upgrade process, do not interrupt the system operation or perform any control actions, as this may cause the upgrade to fail and affect normal system operation.
3. After the upgrade is complete, power off the R1 system and then power it back on to ensure the update is fully applied.

**Please follow the tutorial below to complete this system update. If you encounter any issue, please email to [support@galaxea.ai](mailto:info@galaxea.ai) or call 4008-780-980 for technical support!**

### Software Package Decompression

```Bash
tar -xf ${your_download_path}/Software_V1.0.4_Release.tar.gz -C ~/
chmod +x ~/ota.sh
cd ~
./ota.sh
```

### Embedded Firmware Upgrade

```Bash
cd ~/work/galaxea/install/share/Embedded_Software_Firmware/tools/R1
source ~/work/galaxea/install/setup.bash
bash r1_embedded_firmware_upgrade.sh ../../firmware/R1/V1_0_4
```
