# Galaxea R1 Lite Software Version_V1.1.8_Changelog

## Release Notes

**Product Name:** Galaxea R1 Lite

**Software Version:** SDK V1.1.8

**Ubuntu System:** 20.04 LTS

**ROS Version:** ROS 1 Noetic

**Release Date:** May 7, 2025 (GMT +8) 

1. **Motion Control Update Items:**

    a) Add the `disable_torso` function to the torso control `r1_lite_jointTracker`. When controlling the torso speed, this function prevents torso joint control from pre-empting the control topic and avoids control conflicts.

## Update Tutorial
### Download the Update Package

`atc_standard_x86-V1.1.8.tar.gz`

- Google Drive：[R1 Lite SDK V1.1.8](https://drive.google.com/drive/folders/1-ychh_mtPnq8SWQKQBC41QsDa0rUXa2U?usp=sharing)
- Baidu Cloud: [R1 Lite SDK V1.1.8](https://pan.baidu.com/s/1F2Lwljw6--zppCPaHQmRHA?pwd=V118)



### Update the Embedded Firmware

```Bash
cd {your_download_path}/install/share/Embedded_Software_Firmware/tools/{your_product_name}
bash {your_product_name}_embedded_firmware_upgrade.sh ../../{your_product_name}/V1_1_8
```

### Extract the Package 

```Bash
tar -xf ${your_download_path}/atc_standard_x86-V1.1.8.tar.gz -C ~/
```

### Execute the Module

```Bash
cd {your_download_path}/install/share/startup_config/script/

# R1 LITE
./robot_startup.sh boot ../session.d/ATCStandard/R1LITEBody.d
```
