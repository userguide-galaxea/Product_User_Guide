# Galaxea R1 Pro Software Version_V1.1.8_Changelog

## Release Notes

**Product Name:** Galaxea R1 Pro

**Software Version:** SDK V1.1.8

**Ubuntu System:** 20.04 LTS

**ROS Version:** ROS 1 Noetic

**Release Date:** May 7, 2025 (GMT +8) 

1. **Driver (HDAS) Update Items:**

    a) Fix the problem of the A2 dual arms and grippers being immovable during the VR teleoperation.

2. **Navigation System Update Items:**

    a) Optimize the speed filter to prevent speed from fluctuating.

    b) Fix the failure feedback status issue.

## Update Tutorial

### Download the Update Package

`atc_standard-V1.1.8.tar.gz`

- Google Drive：[R1 Pro SDK V1.1.8](https://drive.google.com/drive/folders/1yeBBmdN1uhNZn7att6LNYVOrpNBLwz5y?usp=sharing)
- Baidu Cloud: [R1 Pro SDK V1.1.8](https://pan.baidu.com/s/19zWgeqxha40Mmu7sGznIYQ?pwd=v118)

### Update the Embedded Firmware

```Bash
cd {your_download_path}/install/share/Embedded_Software_Firmware/tools/{your_product_name}
bash {your_product_name}_embedded_firmware_upgrade.sh ../../{your_product_name}/V1_1_8
```

### Extract the Package 

```Bash
tar -xf ${your_download_path}/atc_standard-V1.1.8.tar.gz -C ~/
```

### Execute the Module

```Bash
cd {your_download_path}/install/share/startup_config/script

# R1 PRO BODY：
./robot_startup.sh boot ../session.d/ATCStandard/R1PROBody.d/

# R1 PRO VR TELEOP：
./robot_startup.sh boot ../session.d/ATCStandard/R1PROVRTeleop.d/
```
