# Galaxea R1 Pro Software Version_V2.0.3_Changelog

## Release Notes

**Product Name:** Galaxea R1 Pro

**Software Version:** SDK V2.0.3

**Ubuntu System:** 22.04 LTS

**ROS Version:** ROS 2 Humble

**Release Date:** May 12, 2025 (GMT +8)

**Update Content:**

1. **Motion Control Update Items:**

    a) Add R1 Pro unboxing demo script.

    b) Optimize torso speed control.

    c) Optimize the parameters of the servo control mode(PID) of A1 robotic arm.  

3. **Driver (HDAS) Update Items:**

    a) Optimize the chassis speed control.

    b) Fix the gripper feedbacks of the A2 robotic arm.

3. **Teleoperation Update Items:**

    a) Fix the torso control in VR Teleop.

4. **Navigation Update Items:**

    a) Optimized logic for obtaining tf in local map updates.

    b) Optimized storage of navigation logs in real-time scenarios.

    c) Optimized loading of parameter file paths.

5. **Tool Module Update Items:**

    a) Added a log file storage service for system-manager state machine.

## Update Instruction

1. During the upgrade process, do not interrupt the system operation or perform any control actions, as this may cause the upgrade to fail and affect normal system operation.
2. After the upgrade is complete, power off the R1 system and then power it back on to ensure the update is fully applied.

## Update Tutorial
### Download the Update Package

`atc_standard-V2.0.3.tar.gz`

`atc_navigation_V2.0.3.tar.gz`

- Google Drive：[ATC_SDK_V2.0.3](https://drive.google.com/drive/folders/1Q-gjRDun5v7nWxJ5Yaqr4230IlDlcdRb?usp=sharing)
- Baidu Cloud: [ATC_SDK_V2.0.3](https://pan.baidu.com/s/1eohcj2zqruORswWf5NOPvQ?pwd=v203)

### Extract the Package 

```Bash
tar -xf ${your_download_path}/atc_standard-V2.0.3.tar.gz -C ~/
```

### Start CAN Driver

```Bash
# Terminal 1
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000 dbitrate 5000000 fd on       
sudo ip link set can0 up
```

### Update Embedded Firmware

```Bash
# Terminal 2
cd ~/ && source install/setup.bash
cd ~/install/Embedded_Software_Firmware/share/tools
cd R1PRO
./r1pro_embedded_firmware_upgrade.sh ls ../../firmware/R1PRO
```

Wait a moment until **"GET OTA finished!!"** appears.

![sdk_ros2_xcu](../assets/sdk_ros2_xcu.png)

<span style="color:red;">**After completing the update, power off the robot and then power it back on.**</span>


### Execute the Module
In the file `atc_standard-V2.0.3.tar.gz`:

```Bash
cd install/startup_config/share/startup_config/script/

# R1PRO BODY:
./robot_startup.sh boot ../session.d/ATCStandard/R1PROBody.d/

# R1PRO VRTELEOP：
./robot_startup.sh boot ../session.d/ATCStandard/R1PROVRTeleop.d/
```

In the file `atc_navigation-V2.0.3.tar.gz`:

```Bash
cd install/startup_config/share/startup_config/script/

# R1PRO NAVIGATION:
./robot_startup.sh boot ../sessions.d/ATCNavigation/R1PROVRTeleopNAV.d/
```

![sdk_ros2_execute](../assets/sdk_ros2_execute.png)

### Terminate ALL
Execute the following conmand to terminate all processes initiated by the above operations.

```Bash
tmux kill-server
```
